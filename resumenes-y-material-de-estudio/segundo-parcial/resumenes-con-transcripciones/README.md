# Aclaración

En la **unidad n°7**, en la sección 1.1 (Variables), en el apartado "Observación", dice que se recomienda quedarse con el material de la presentación. En realidad, conviene quedarse con lo expuesto en el Word: el nombre de una variable puede contener cualquier carácter. En los parciales, la respuesta correcta siempre es que el nombre de una variable puede contener cualquier carácter.

En la **unidad n°12**, en "Características y Arquitectura de BD para Dispositivos Móviles", por alguna razón no se imprimió bien el cuadro de "Ventajas" (aunque sí se imprimió bien el cuadro de "Desventajas"). A continuación lo que decía el cuadro:

Ventajas
• Funciona offline
• Muy rápida (acceso local)
• No depende de red
• Bajo consumo de batería
• Fácil despliegue
